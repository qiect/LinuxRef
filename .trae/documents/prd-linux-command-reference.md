## 1. 产品概述

Linux命令快速查询应用 —— 一个面向开发者和运维人员的命令速查工具，提供通俗易懂的中文解释和全面的命令覆盖，帮助用户快速找到所需命令并理解其用法。
- 解决问题：Linux命令繁多难记，man手册晦涩难懂，新手学习曲线陡峭
- 目标用户：Linux初学者、开发者、运维工程师、系统管理员

## 2. 核心功能

### 2.1 用户角色
| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 无需注册 | 浏览和搜索所有命令 |

### 2.2 功能模块
1. **主页**：搜索栏、命令分类导航、热门命令推荐、每日一令
2. **命令详情页**：命令语法、通俗解释、常用示例、相关命令

### 2.3 页面详情
| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 主页 | 搜索栏 | 支持命令名、中文关键词、功能描述模糊搜索，实时过滤 |
| 主页 | 分类导航 | 按功能分类浏览命令（文件操作、进程管理、网络工具、权限管理、文本处理、系统信息、磁盘管理、压缩解压、用户管理、软件包管理） |
| 主页 | 热门命令 | 展示最常用的Linux命令快捷卡片 |
| 主页 | 每日一令 | 随机展示一个命令及其通俗解释 |
| 命令详情 | 语法格式 | 命令的标准语法和参数说明 |
| 命令详情 | 通俗解释 | 用生活化的比喻解释命令的功能 |
| 命令详情 | 常用示例 | 3-5个实际使用场景和命令示例 |
| 命令详情 | 相关命令 | 推荐功能相近或搭配使用的命令 |

## 3. 核心流程

用户打开应用 → 看到搜索栏和分类导航 → 通过搜索或分类找到目标命令 → 点击命令卡片查看详情 → 阅读通俗解释和示例 → 通过相关命令继续探索

## 4. 用户界面设计

### 4.1 设计风格
- 主色调：深色终端风格（#0D1117 深黑背景 + #58A6FF 终端蓝高亮 + #7EE787 终端绿代码色）
- 辅助色：#F0883E 橙色警告/高亮，#BC8CFF 紫色分类标签
- 按钮风格：圆角胶囊按钮，hover时发光效果
- 字体：代码区使用 JetBrains Mono，正文使用 Noto Sans SC
- 布局风格：左侧分类侧边栏 + 右侧内容区，终端风格卡片
- 图标风格：简约线条图标，搭配终端光标闪烁动效

### 4.2 页面设计概览
| 页面名称 | 模块名称 | UI元素 |
|----------|----------|--------|
| 主页 | 搜索栏 | 大号输入框，终端光标闪烁动画，搜索图标，placeholder提示"输入命令或关键词..." |
| 主页 | 分类导航 | 左侧垂直导航栏，分类图标+文字，选中态发光效果 |
| 主页 | 命令卡片网格 | 终端风格卡片，命令名绿色高亮，简短描述，hover浮起+发光 |
| 主页 | 每日一令 | 顶部横幅，打字机效果展示命令 |
| 命令详情 | 语法区 | 深色代码块，语法高亮，参数彩色标注 |
| 命令详情 | 解释区 | 生活化图标+通俗文字，比喻用引号高亮 |
| 命令详情 | 示例区 | 可复制的代码块，带复制按钮，运行结果预览 |
| 命令详情 | 相关命令 | 底部横向滚动卡片 |

### 4.3 响应式设计
- 桌面优先设计，侧边栏常驻
- 平板：侧边栏可折叠为汉堡菜单
- 手机：底部标签栏导航，卡片单列布局
