# LinuxRef

Linux 命令速查 - 快速查询通俗易懂的 Linux 命令与目录结构

## 功能

- **命令速查**：支持按命令名、中文关键词、功能描述模糊搜索，实时过滤
- **分类浏览**：10 大分类（文件操作、文本处理、进程管理、网络工具、权限管理、系统信息、磁盘管理、压缩解压、用户管理、软件包管理）
- **命令详情**：语法格式、通俗解释、常用示例、相关命令
- **目录结构**：树形可视化展示 Linux 15 个核心目录，点击展开查看通俗解释、关键文件、运维提示
- **每日一令**：随机推荐一个命令
- **收藏功能**：星标收藏常用命令
- **键盘快捷键**：`/` 搜索、`↑↓` 导航、`Enter` 查看、`Esc` 清空

## 技术栈

- Vue 3 + TypeScript
- Vite
- Tailwind CSS
- Lucide Icons
- 纯前端架构，无后端依赖
